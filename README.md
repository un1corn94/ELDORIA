# Chroniken von Eldoria

Ein Fantasy-Rollenspiel in 3D, das direkt im Browser läuft.

- `public/index.html` – das komplette Spiel (eine einzige Datei, inklusive Mehrspieler-Modus mit Raum-Code)
- `netlify.toml` – sagt Netlify, dass der Ordner `public` veröffentlicht wird

Jede Änderung im Zweig `main` wird von Netlify automatisch übernommen und ist kurz danach online.
